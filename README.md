# AIMA, גרסת GitHub Pages

זוהי חבילה סטטית מלאה של האתר. הגולשים לא צריכים חשבון ChatGPT ולא צריכים להתחבר בכלל.

## העלאה ראשונה ל-GitHub

1. חלצו את קובץ ה-ZIP ופתחו את התיקייה `AIMA-GitHub`.
2. פתחו Repository חדש ב-GitHub בשם `aima-site` ובחרו Public.
3. העלו לשורש ה-Repository את **כל הקבצים והתיקיות שנמצאים בתוך** `AIMA-GitHub`, כולל `index.html`, `assets`, `content`, `studio` והתיקייה הנסתרת `.github`.
4. בסיום, `index.html` חייב להופיע ישירות במסך הראשי של ה-Repository. אל תעלו רק את `index.html`, ואל תיצרו מצב שבו הוא נמצא בתוך `AIMA-GitHub/AIMA-GitHub`.
5. ב-GitHub פתחו `Settings` ואז `Pages`.
6. תחת `Build and deployment`, בחרו `GitHub Actions`.
7. אחרי כדקה פתחו את לשונית `Actions` וודאו שהפעולה `Publish AIMA site` הסתיימה בירוק.

אפשר לפתוח את `index.html` מהמחשב לבדיקה מהירה של העיצוב, אבל התפקוד המלא של הקישורים וה-Studio נבדק דרך אתר GitHub Pages לאחר ההעלאה.

## חיבור הדומיין

1. ב-`Settings` ואז `Pages`, כתבו את הדומיין בשדה `Custom domain` ושמרו.
2. אצל ספק הדומיין הוסיפו את רשומות ה-DNS ש-GitHub מציג לכם. עבור `www` זו בדרך כלל רשומת CNAME אל `<github-user>.github.io`.
3. אחרי שהבדיקה עוברת, סמנו `Enforce HTTPS`.

אל תנחשו רשומות DNS. העתיקו את הערכים המדויקים ש-GitHub מציג במסך של ה-Repository שלכם.

## ניהול אמן החודש, שירי השבוע ותוכן נוסף בלי התחברות

פתחו באתר שלכם את `/studio/`. זהו סטודיו תוכן שעובד בדפדפן בלבד:

1. החליפו את אמן החודש, הוסיפו שירים לרוטציה השבועית, או הוסיפו אירוע, עדכון ומשאב.
2. לחצו `הורדת קובץ תוכן`.
3. ב-GitHub החליפו את הקובץ `content/community-overrides.json` בקובץ שירד.
4. בצעו Commit. האתר יתעדכן אוטומטית.

שיר השבוע מתחלף אוטומטית פעם בשבוע מתוך רשימת השירים שב-Studio. אמן החודש נשאר קבוע עד שתבחרו אמן אחר.

הסטודיו אינו מחובר לחשבון כלשהו ואינו מפרסם ישירות. לכן הוא בטוח לשימוש ללא סיסמה, אבל רק מי שיש לו הרשאת כתיבה ל-Repository יכול לפרסם את הקובץ באתר.

## הגנת תוכן

החבילה מקשה על העתקה רגילה, שמירה, גרירה ותפריט לחיצה ימנית, בלי לחסום מנועי חיפוש, תצוגות מקדימות ברשתות או התאמה לנייד. חשוב לדעת שאין דרך למנוע לחלוטין העתקה של אתר ציבורי, כי הדפדפן חייב לקבל את הקוד כדי להציג אותו.
